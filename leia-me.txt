terrivel world - estrutura do site

REGRA: todo nome de arquivo ou pasta, daqui pra frente, é escrito só com letras minúsculas.

  index.html                 página inicial (única na pasta principal)
  main/                      arquivos comuns a todo o site
      estilo.css             visual compartilhado
      site.js                barra superior, modo claro/escuro, idioma EN/BR, estrelas, menu
      lista.csv              planilha de jogos (lida pela página gamelog)
  gamelog/
      gamelog.html           página gamelog
      gamelog.js             código da página
      char/                  imagens da coluna CreationImage
      images/                imagens das colunas GameLogo e ImageMain
  (print, projects e files serão criadas depois, cada uma com a sua página html)

PLANILHA
  Exporte como "CSV UTF-8" e salve como lista.csv dentro de main. Trocar esse arquivo no GitHub atualiza o gamelog.
  Imagens: escreva só o nome do arquivo na célula; a página procura em char/ (CreationImage) ou images/ (as demais),
  sempre em minúsculas. Um endereço completo (https://...) também funciona.

PUBLICAR NO GITHUB PAGES
  1. Crie um repositório público em github.com.
  2. Envie o CONTEÚDO desta pasta (index.html, main e gamelog), sem a pasta externa.
     Se já existir algo enviado antes com nomes em maiúsculas, apague tudo no repositório e envie de novo.
  3. Settings > Pages > Deploy from a branch > main > / (root).
  4. O site abre no endereço mostrado ali, em cerca de um minuto.

TESTAR NO COMPUTADOR
  O gamelog lê a planilha com fetch(), e os navegadores bloqueiam isso quando o arquivo é aberto direto do disco.
  Use um servidor local (por exemplo, "python -m http.server" dentro da pasta) ou teste direto no GitHub Pages.
